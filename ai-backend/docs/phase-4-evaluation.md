# Phase 4 Evaluation Metrics

To rigorously evaluate the pricing engine when real market data is integrated:

1. **Price Prediction Error**: Track how closely recommended prices align with actual conversion-generating prices.
2. **Mean Absolute Error (MAE)**: Track accuracy without percentage skew.
3. **Mean Absolute Percentage Error (MAPE)**: Measure overall model reliability.
4. **Confidence Calibration**: Verify if predictions marked "high" confidence actually convert faster than those marked "low".
5. **Artisan Satisfaction Rate**: Feedback from artisans adjusting or accepting the suggested price.
6. **Profitability Improvement**: Track if artisans see higher margins over a 6-month tracking period.
